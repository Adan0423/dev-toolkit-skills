# Prompt: Mejorar README y documentación

Usa este prompt para actualizar la documentación de un proyecto tras cambios funcionales o de estructura.

Prompt breve:

```text
Revisa el estado actual de README.md, CHANGELOG.md y cualquier docs/ relevante.

Identifica qué se debe actualizar, mantiene el tono del proyecto y entrega un plan de documentación sincronizado con el código.
```
