# Prompt: Crear un skill con el flow de skill-creator

Usa el skill `meta/skill-creator` cuando quieras materializar una nueva skill, mejorarla o dejarla lista para evaluación.

Prompt breve:

```text
Usa la skill `skill-creator` para crear o perfeccionar una skill reutilizable dentro del repositorio.

Necesito una captura de intención, entrevista técnica, borrador de SKILL.md, referencias y casos de prueba verificables.

La skill debe quedar global respecto al stack y evitar el nombre del proyecto de origen en su description.
```
