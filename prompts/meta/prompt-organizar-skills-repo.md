# Prompt: Organizar y extraer skills reutilizables

Usa este prompt para inspeccionar uno o varios proyectos y producir una estructura de skills limpia, estable y reutilizable.

Prompt breve:

```text
Analiza el proyecto o proyectos enviados y extrae patrones reutilizables para convertirlos en skills del repositorio.

Enfócate en stack, riesgos, decisiones de arquitectura, prompts concretos y referencias.

Entrega una lista de skills candidatas, con nombre en kebab-case, categoría, tecnología y una descripción de activación.

Si una parte del conocimiento es demasiado específica del proyecto de origen, no la conviertas en skill global.
```
