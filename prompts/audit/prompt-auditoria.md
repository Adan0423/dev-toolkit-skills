# Prompt: Auditoría de sistema

Usa esta entrada para lanzar una auditoría full-stack del repositorio.

Orienta la revisión a arquitectura, frontend, backend, APIs, seguridad, UX, bases de datos, dependencias y pruebas. La salida debe incluir hallazgos con riesgo, priorización y cambios concretos.

```text
Analiza el proyecto completo, comprende su stack real y entrega un plan de corrección y mejora.

Revisa estructura, flujo funcional, UI, API, seguridad, rendimiento, RLS, pruebas y configuración.
```
