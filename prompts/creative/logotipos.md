<a id="log-01"></a>
## LOG-01 · Símbolo original de marca

```text
Diseña un símbolo original para {{marca}}, sector {{sector}} y atributos {{atributos}}. Construye {{concepto}} con pocas formas, geometría clara y espacio negativo intencional. Debe funcionar en una tinta y pequeño, sin gradientes obligatorios. Símbolo plano aislado en {{fondo}}, sin texto, textura o mockup. Evita clichés del sector y similitudes con {{referencias_a_evitar}}. Entrega concepto raster; no afirma archivo vectorial ni disponibilidad de registro.

Genera la imagen en {{formato}} para {{destino}}. Las referencias adjuntas guían únicamente su función indicada. Configura tamaño y cantidad en los controles disponibles. Si una capacidad no existe, explica el paso pendiente; no simula archivos editables o transparencia.

Control de calidad: Evaluar silueta, equilibrio, lectura pequeña y diferenciación visual.
```

## LOG-02 · Wordmark con nombre exacto

```text
Crea un wordmark con el nombre exacto "{{nombre_exacto}}", personalidad {{personalidad}} y familia visual {{familia_tipografica}}. Ajusta proporciones y espaciado óptico; introduce {{detalle_distintivo}} sin perder lectura. Color {{color}} en {{fondo}}, distribución {{distribucion}}. Sin tagline adicional. Si el generador no reproduce letras, entrega referencia y propone composición del nombre con texto editable; no presenta letras deformadas como arte final.

Genera la imagen en {{formato}} para {{destino}}. Las referencias adjuntas guían únicamente su función indicada. Configura tamaño y cantidad en los controles disponibles. Si una capacidad no existe, explica el paso pendiente; no simula archivos editables o transparencia.

Control de calidad: Leer letra por letra y comprobar kerning y tamaño pequeño.
```

## LOG-03 · Icono de aplicación

```text
Diseña un icono para {{aplicacion}} que represente {{funcion}} mediante {{metafora}}. Composición compacta, una forma dominante, bordes claros y paleta {{paleta}}. Deja margen para máscaras circulares o redondeadas; no dibuja dispositivo. Contraste y lectura a 32 px, sin letras pequeñas o logos ajenos. Presentación plana sobre {{fondo}}, sin sombras que impidan reutilización.

Genera la imagen en {{formato}} para {{destino}}. Las referencias adjuntas guían únicamente su función indicada. Configura tamaño y cantidad en los controles disponibles. Si una capacidad no existe, explica el paso pendiente; no simula archivos editables o transparencia.

Control de calidad: Comprobar reconocimiento, margen de seguridad y relación con la función.
```

<a id="log-04"></a>
## LOG-04 · Construir un SVG editable real

```text
Actúa como diseñador y desarrollador SVG. Construye un archivo SVG para {{marca}} a partir de {{concepto_o_referencia}}, con geometría {{geometria}}, viewBox, formas o paths editables y color {{color}}. Fondo transparente y lectura a 24 px. No incrustes raster para fingir vector. Usa texto editable {{texto_exacto}} solo si se requiere, indicando fuente; convierte a contornos únicamente con herramientas disponibles. Evita scripts, eventos y recursos externos. Entrega código y archivo si puedes escribirlo; si la referencia excede lo reproducible, indica simplificaciones.

Entrega SVG editable para {{destino}} y una vista previa solo si puedes renderizarla. Si no puedes escribir archivos, entrega el código completo. Explica simplificaciones y dependencias de tipografía; no presenta una imagen raster como SVG.

Control de calidad: Validar XML, viewBox, recorte, ausencia de raster/scripts y versión monocroma.
```
