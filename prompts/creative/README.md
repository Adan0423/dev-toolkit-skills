## Elegir el prompt adecuado

Para una foto existente comienza por EDI. Para conservar una identidad utiliza RET
con fotografía de referencia. Para catálogo exacto usa ECO; para campaña publicitaria
PRO o CRE. Para logo editable simple, LOG-04 produce código SVG. Para una web funcional,
WEB requiere contexto de código o CMS, no solo un generador de imágenes.

Los prompts describen resultados y límites; no garantizan una identidad inalterada,
archivos 3D editables ni aprobación de accesibilidad. Revisa la salida según cada bloque.
Las herramientas que no admitan un requisito deben indicar el paso pendiente.

## Mantenimiento

Edita los Markdown originales, conserva IDs y regenera el índice desde la raíz:

```sh
python -B scripts/build_prompt_catalog.py
python -B scripts/build_prompt_catalog.py --check
```

El índice JSON contiene categoría, modo, ruta, ancla y variables de cada prompt.
No hace falta cargar todas las categorías en una conversación.
La comprobación del catálogo verifica estructura e índice; no ejecuta generación visual.
