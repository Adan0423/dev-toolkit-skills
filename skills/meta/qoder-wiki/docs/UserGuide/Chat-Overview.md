# Descripción general del chat

Fuente: https://docs.qoder.com/en/user-guide/chat/overview

## Competencias básicas

La sesión inteligente de Qoder contiene tres modos:

- Preguntas y respuestas inteligentes
- Agente
-Expertos

Las capacidades generales incluyen:

- Cambio gratuito entre múltiples modos de chat
- Conciencia ambiental automática
- Llamada de herramienta
- ejecución de comando
- Modificaciones a nivel de proyecto de varios archivos
- memoria a largo plazo

## Iniciar un nuevo chat

- Abrir panel de sesión: `Cmd/Ctrl + L`
- Seleccione el modo de chat en el panel
- Ingrese requisitos estructurados con el contexto necesario.

## Ingresar sugerencias

- Aclarar objetivos y resultados esperados.
- Documentos complementarios, imágenes, cambios de código y otro contexto.
- Describir la pila de tecnología, las especificaciones y los requisitos de salida.
- Iterar los requisitos a través de múltiples rondas de comentarios.

## Modificación y revisión de código

En modo agente, Qoder admite:

- Generación y aplicación de múltiples archivos.
- ver diferencias
- Aceptar o rechazar cambios uno por uno
- Continuar agregando requisitos en múltiples rondas de sesiones.
- Usar reversión de instantáneas

## Habilidades relacionadas

- Contexto: archivos, directorios, imágenes, envíos, reglas, etc.
- Memoria: almacena automáticamente las preferencias personales y del proyecto
- Herramientas: buscar, leer y escribir, comandos, resolución de problemas
- MCP: acceso a herramientas y servicios externos
