#Modo Preguntar

Fuente: https://docs.qoder.com/zh/user-guide/chat/ask

## Escenarios aplicables

El modo Preguntar es adecuado para tareas de "preguntas y respuestas" sin cambiar directamente el código. Usos comunes:

- Explica el código.
- Ideas de optimización
- Corregir sugerencias
- Solucionar errores de compilación
- Responder preguntas de programación.

## Uso

- Abra el panel de sesión inteligente: `Cmd/Ctrl + L`
- Seleccione `Preguntas y respuestas inteligentes` en el menú desplegable
- Enviar el código seleccionado o el archivo completo al chat para hacer preguntas

## Características

- Más ligero
- Adecuado para consultoría y análisis.
- Basado principalmente en sugerencias y explicaciones, no en ejecución de un extremo a otro.
