# herramienta

Fuente: https://docs.qoder.com/zh/user-guide/chat/tools

## Descripción general

Qoder tiene muchas herramientas integradas, que cubren búsqueda, edición, terminal, ubicación de problemas y actualización de memoria, y se puede conectar a herramientas MCP.

## Clasificación de herramientas

### buscar

- Búsqueda de base de código
- Búsqueda de archivos
- Búsqueda de fragmentos de código
- Navegación por catálogo
- Búsqueda web
- Captura de contenido web

### editar

- Modificar archivos
- Ver archivos

### Ejecutar comando

- ejecutar comando
- Obtener salida del terminal

### Encontrar problemas

- Obtener problemas de código en el proyecto.

### Actualizar memoria

- Actualizar la memoria persistente según la entrada del usuario.

### Herramientas MCP

- Elija su propia herramienta MCP por descripción
- Generalmente solicita confirmación antes de la ejecución.
- Se puede combinar con la configuración de operación automática para reducir la intervención manual
