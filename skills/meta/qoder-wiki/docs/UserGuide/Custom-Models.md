# Modelo personalizado

Fuente: https://docs.qoder.com/zh/user-guide/chat/custom-models

## Descripción general

Qoder admite el acceso a recursos de modelos de terceros a través de una clave API.

- Versiones aplicables: `Pro Trial / Pro / Pro+ / Ultra`
- Proveedores de servicios enumerados en el documento actual: Alibaba Cloud Bailian, Zhipu, Kimi, MiniMax
- Repo Wiki utiliza un modelo fijo y seguirá consumiendo créditos Qoder de forma independiente

## Agregar pasos

1. Abra "Configuración de Qoder"
2. Ingrese al panel "Modelo" a la izquierda.
3. Haga clic en `+Agregar modelo`
4. Seleccione el proveedor de servicios y complete la clave API.
5. Comience a usar después de verificar la conexión.

## Capacidades de gestión

- Editar alias del modelo
- Eliminar modelo
- Activar o desactivar la visualización del modelo.

## Preguntas frecuentes

- El modelo personalizado en sí no consume créditos Qoder y el costo lo paga el proveedor de servicios del modelo.
- Admite agregar múltiples modelos o múltiples claves para el mismo proveedor de servicios
- Cuando la adición falla, concéntrese en verificar la clave API, el saldo, los permisos y la red.
