#Compresión de contexto

Fuente: https://docs.qoder.com/en/user-guide/chat/smart-context-control

## Descripción general

La compresión de contexto se utiliza para optimizar la eficiencia del uso del contexto en conversaciones largas o escenarios de tareas grandes, lo que ayuda al modelo a retener información clave y reducir la ocupación de contexto no válida.

## Función

- Preservar el contexto que es verdaderamente importante para la tarea.
- Reducir el ruido en conversaciones largas.
- Estabilidad mejorada de tareas complejas.
- Ayuda a controlar el consumo de ventanas de contexto.

## Adecuado para la escena

- Múltiples rondas de largas conversaciones.
- Múltiples tareas de archivos
- Codificación de tareas con más contexto y enlaces más largos.
