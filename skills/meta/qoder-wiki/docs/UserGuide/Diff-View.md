# Vista diferencial

Fuente: https://docs.qoder.com/zh/user-guide/diff-view

## Descripción general

La vista Diff se utiliza para revisar los cambios de código generados por Qoder, comparando el contenido original con los cambios recomendados.

## Propósito principal

- Ver cambios a nivel de archivo
- Navegar de un lugar a otro dentro del archivo
- Aceptar o rechazar cambios
- Cambiar revisiones entre archivos

## Combinaciones comunes

- Se utiliza con el modo Agente para revisar múltiples modificaciones de archivos.
- Úselo con sesiones de varios turnos para iterar el código paso a paso
- Combinado con instantáneas y deshacer para controlar el riesgo de cambios.
