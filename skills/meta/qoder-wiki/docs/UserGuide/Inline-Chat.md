# Conversación entre líneas

Fuente: https://docs.qoder.com/en/user-guide/inline-chat

## Descripción general

Inline Chat le permite iniciar una conversación directamente en el archivo actual en el editor, lo que es adecuado para modificar el código existente.

## Método abierto

- MacOS: `Cmd + I`
- Windows: `Ctrl + I`

## Contexto

Ingrese `#` en una línea de conversación para agregar contexto, por ejemplo:

- documento
- regla

## Uso típico

- Seleccione un fragmento de código para solicitar refactorización, comentarios o reparaciones.
- Sin seleccionar el código, solicite directamente generar un nuevo fragmento en el archivo actual

## Adecuado para la escena

- Modificación parcial de fila única
- Reescritura rápida de código
- Finalización y mejora a pequeña escala.
