# CLI para comenzar rápidamente

Fuente: https://docs.qoder.com/zh/cli/quick-start

## Método de instalación

- `curl -fsSL https://qoder.com/install | bash`
- `brew install qoderai/qoder/qodercli --cask`
- `npm install -g @qoder-ai/qodercli`

## Plataforma de soporte

- MacOS
-Linux
-Windows (Terminal de Windows)
- Arquitectura de CPU: `arm64`, `amd64`

## Método de inicio de sesión

- Inicio de sesión interactivo: utilice `/login` después de ejecutar `qodercli`
-Inicio de sesión de variable de entorno: establecer `QODER_PERSONAL_ACCESS_TOKEN`

## Comandos comunes

- `qodercli --versión`
- `actualización qodercli`
- `/ iniciar sesión`
- `/cerrar sesión`

## Instrucciones adicionales

- La actualización automática está habilitada de forma predeterminada
- `autoUpdates` se puede establecer en `false` en `~/.qoder.json`
