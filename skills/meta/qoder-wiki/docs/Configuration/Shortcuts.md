# tecla de acceso directo

Qoder lo ayuda a mejorar la eficiencia del trabajo a través de teclas de acceso directo, que cubren conversaciones entre líneas, chat de IA, navegación con vista diferencial y otras funciones.

## de uso común

| Orden | macos | ventanas |
| --- | --- | --- |
| Activar/desactivar el chat AI | `⌘L` | `Ctrl L` |
| Abrir configuración general | `⌘` | `Ctrl` |
| Abrir configuración de Qoder | `⌘ ⇧,` | `Ctrl Mayús,` |
| Abrir paleta de comandos | `⌘ ⇧P` | `Ctrl Mayús P` |

## charlar

| Orden | macos | ventanas |
| --- | --- | --- |
| enviar mensaje | `⏎` | `⏎` |
| Inserte una nueva línea en el cuadro de entrada | `⇧ ⏎` | `Cambio ⏎` |
| Aceptar todos los cambios sugeridos | `⌘ ⏎` | `Ctrl ⏎` |
| Rechazar todos los cambios propuestos | `⌘ ⌫` | `Ctrl Retroceso` |

## conversación interlineal

| Orden | macos | ventanas |
| --- | --- | --- |
| Abrir una sesión interlínea | `⌘yo` | `CtrlI` |
| Enviar a conversación | `⌘L` | `Ctrl L` |

## Selección de código y selección contextual.

| Orden | macos | ventanas |
| --- | --- | --- |
| Agregar contexto al chat | `#` | `#` |
| Llamar al comando de acceso directo | `/` | `/` |
| Agregue el bloque de código actualmente seleccionado al chat | `⌘L` | `Ctrl L` |

## Vista diferencial

| Orden | macos | ventanas |
| --- | --- | --- |
| Aceptar cambio único | `⌘ ⇧ ⏎` | `Ctrl Mayús ⏎` |
| Rechazar cambios individuales | `⌘ ⇧ ⌫` | `Ctrl Mayús Retroceso` |
| Aceptar todos los cambios en el archivo. | `⌘ ⏎` | `Ctrl ⏎` |
| Rechazar todos los cambios en el archivo | `⌘ ⌫` | `Ctrl Retroceso` |
| Saltar al siguiente archivo | `⌘ ⇧ [` | `Ctrl Mayús [` |
| Saltar al archivo anterior | `⌘ ⇧ ]` | `Ctrl Mayús]` |
| Saltar al siguiente cambio | `⌥J` | `Alt J` |
| Saltar al cambio anterior | `⌥K` | `Alt K` |

## Modo de búsqueda

| comando | macos | ventanas |
| --- | --- | --- |
| Abre el panel de misiones | `⌘E` | `Ctrl E` |
| Abre la ventana global de Quest | `⌘ ⌥ E` | `Ctrl Alt E` |
