## ¿Por qué necesitas un agente?

Las redes corporativas suelen utilizar servidores proxy HTTP para interceptar tráfico de la red antes de que se envíe al destino, con el fin de detectar tráfico sospechoso o restringir el contenido que ingresa a la red corporativa. a través de un proxy.

## Cómo configurar un proxy de red

1. Vaya a **Preferencias** > **Configuración de Qoder**
2. Busque **Proxy de red** en **Avanzado**
3. Seleccione uno de los siguientes modos de proxy:

### Usar la configuración global del sistema (predeterminada)

Cómo utilizar tus propias herramientas para crear tu propia configuración.

### Configurar manualmente el proxy de red

Ingrese la dirección y el puerto del proxy. Qoder admite los siguientes tipos de proxy:

- HTTP
- HTTPS
- CALCETINES5

> **Nota:** Asegúrese de proporcionar la dirección completa, incluido el protocolo y el puerto. Ejemplo: `https://127.0.0.xxx:8080`
