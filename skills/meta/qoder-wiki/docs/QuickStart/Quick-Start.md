# Inicio rápido

Este artículo lo llevará a través de un proyecto práctico para experimentar las funciones principales de Qoder como usuario individual. Al finalizar, estará familiarizado con la predicción de sugerencias entre líneas (NES), la conversación entre líneas y la conversación inteligente, herramientas clave para la codificación asistida por IA.

> Qoder Personal Edition ofrece actualmente una prueba gratuita a todos los usuarios. El período de prueba puede ajustarse. Consulte Actualizaciones de productos para obtener la información más reciente.

## 1. Instalación

Descargue e instale Qoder desde el [sitio web oficial de Qoder] (https://qoder.com/download).

## 2. Iniciar sesión

1. En la esquina superior derecha de Qoder IDE, haga clic en el icono de usuario o utilice el método abreviado de teclado (`⌘` `⇧` `,` (macOS) o `Ctrl` `Shift` `,` (Windows)) y seleccione **Iniciar sesión**.
2. En la página web abierta:
   - Haga clic en **Registrarse** en la parte inferior y complete el registro, o
   - Regístrese directamente con una cuenta de Google o GitHub.
3. Regrese al IDE de Qoder. Ahora eres libre de utilizar todas las funciones.

## 3. Abra el proyecto

Puede optar por utilizar un proyecto local o clonar el proyecto de muestra de GitHub.

### Usar proyecto local

1. Haga clic en **Abrir** o utilice el método abreviado de teclado:
   - Mac OS: `⌘` `O`
   - Windows: `Ctrl` `O`
2. Busque la carpeta del proyecto, seleccione el archivo y ábralo.

### Clonar la base del código

1. Haga clic en **Clonar repositorio**.
2. En la barra de búsqueda superior:
   - Ingrese la URL del proyecto y haga clic en **Clonar desde URL**, o
   - Haga clic en **Clonar desde GitHub** y siga las indicaciones.
3. Siga los pasos para completar la clonación del proyecto.

## 4. Explorar funciones

### Activar NES

NES proporciona edición inteligente basada en el contexto en el cursor para ayudarte a iniciar rápidamente la codificación asistida por IA.

1. Ingrese algunos fragmentos de código o describa los requisitos del código en lenguaje natural. Por ejemplo: "Inicializar una lista".
2. Presione `⌥` `P` (macOS) o `Alt` `P` (Windows) y las sugerencias aparecerán automáticamente.
3. Presione **Tab** para aceptar la sugerencia.

NES admite la edición de varias líneas y el autocompletado fluido.

### Iniciar diálogo entre filas

Obtenga ayuda de IA directamente en el contexto de su código mediante conversaciones en línea.

1. En el editor de código Qoder, presione `⌘` `I` (macOS) o `Ctrl` `I` (Windows). Se abrirá la ventana de conversación interlínea.
2. Ingrese la solicitud y envíela. Por ejemplo: "Agregar una función de procesamiento de carga de archivos"
3. Para aplicar el código generado por IA, presione `⌘` `⏎` (macOS) o `Ctrl` `Enter` (Windows).

### Iniciar conversación sobre IA

Utilice el panel de Conversación inteligente o presione `⌘` `L` (macOS) o `Ctrl` `L` (Windows) para manejar tareas más complejas en el modo Pregunta inteligente o Agente.

1. Ingrese la solicitud en el panel de conversación inteligente a la derecha. Por ejemplo: "Crear y ejecutar una prueba para esta función"
2. Envíe una solicitud. El agente generará archivos de prueba que contienen casos de uso relevantes.
3. Haga clic en **Ejecutar** cuando se le solicite, o presione `⌘` `⏎` (macOS) o `Ctrl` `Enter` (Windows) para ejecutar la prueba.
