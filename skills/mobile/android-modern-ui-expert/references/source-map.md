## Reference application

- Now in Android: https://github.com/android/nowinandroid

Now in Android is useful as an implementation reference for Kotlin + Compose, Material 3, adaptive layouts, dark mode, architecture, screenshot tests, modularization, benchmarks, and baseline profiles. Do not blindly copy its module structure into smaller projects.
