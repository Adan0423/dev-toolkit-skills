# Seguridad arquitectónica

## Principios

- security by design;
- secure by default;
- least privilege;
- defense in depth;
- fail secure;
- explicit trust boundaries;
- minimal attack surface;
- simple mechanisms.

## Revisión

- identidad y autorización;
- secretos y keys;
- datos sensibles;
- input/output boundaries;
- comunicación externa/interna;
- permisos de procesos y servicios;
- dependencias y supply chain;
- logging/audit;
- manejo de errores;
- backups/retention si aplica;
- threat model para flujos críticos.
