# Contratos de salida

## Auditoría

- arquitectura detectada;
- mapa de módulos y dependencias;
- top problemas por severidad;
- basura/candidatos a limpieza por confianza;
- propuesta de estructura objetivo;
- plan incremental;
- quality gates.

## Proyecto nuevo

- supuestos;
- drivers arquitectónicos;
- arquitectura elegida y alternativas descartadas;
- estructura de repositorio;
- contratos/módulos;
- datos e integraciones;
- seguridad/observabilidad;
- código base ejecutable;
- definition of done.

## Migración/refactor

- estado inicial;
- objetivo;
- pasos pequeños;
- compatibilidad;
- rollback strategy;
- checks por etapa;
- residuos eliminados con evidencia.
