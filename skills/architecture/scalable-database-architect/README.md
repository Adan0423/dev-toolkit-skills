# Scalable Database Architect

Skill profesional para arquitectura, optimización y seguridad de bases de datos.

Incluye:
- diseño SQL y NoSQL según access patterns;
- PostgreSQL, MongoDB y DynamoDB como modelos de referencia;
- relaciones, normalización y denormalización deliberada;
- auditoría de tablas/columnas/índices innecesarios;
- EXPLAIN y medición de queries;
- funciones y transacciones;
- query budgets, límites, paginación y pooling;
- RLS/RBAC y mínimo privilegio;
- query parameterization y protección contra injection;
- migraciones y observabilidad;
- plantillas de auditoría.

Usar `SKILL.md` como archivo principal.
