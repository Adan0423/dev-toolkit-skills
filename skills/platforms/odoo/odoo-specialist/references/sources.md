# Fuentes oficiales y versión

Investigación inicial 2026-09-30 con referencia 19.0. No implica que todos los proyectos
usen esta versión. Consulta versión/edición exacta y código de addons instalados.
Las páginas de odoo.com presentaron timeouts durante investigación; se consultó también
el repositorio oficial odoo/documentation. Para una regla cambiante verifica texto
completo de la rama real, no solo un resumen del buscador.

| Fuente | Decisión |
|---|---|
| [Documentación Odoo](https://www.odoo.com/documentation/) | Selección de versión/apps |
| [Tutorial servidor](https://www.odoo.com/documentation/19.0/developer/tutorials/server_framework_101.html) | Desarrollo de addons |
| [Manifest oficial](https://github.com/odoo/documentation/blob/19.0/content/developer/reference/backend/module.rst) | Dependencias/datos/assets |
| [ORM](https://www.odoo.com/documentation/19.0/developer/reference/backend/orm.html) | Recordsets, tipos, relaciones |
| [Seguridad](https://github.com/odoo/documentation/blob/19.0/content/developer/reference/backend/security.rst) | ACL/reglas y métodos |
| [Multiempresa](https://www.odoo.com/documentation/19.0/developer/howtos/company.html) | Contexto y consistencia |
| [Owl](https://www.odoo.com/documentation/19.0/developer/reference/frontend/owl_components.html) | Componentes soportados |
| [Framework UI](https://www.odoo.com/documentation/19.0/developer/reference/frontend/framework_overview.html) | Services/registries/web client |
| [JSON-2](https://github.com/odoo/documentation/blob/19.0/content/developer/reference/external_api.rst) | API, acceso y transacciones |
| [RPC anterior](https://www.odoo.com/documentation/19.0/developer/reference/external_rpc_api.html) | Compatibilidad/deprecaciones, revalidar calendario |
| [Importación](https://github.com/odoo/documentation/blob/19.0/content/applications/essentials/export_import_data.rst) | IDs/mapeo y pruebas |
| [Testing](https://github.com/odoo/documentation/blob/19.0/content/developer/reference/backend/testing.rst) | Runtime, casos y runner |
| [Online/Odoo.sh](https://github.com/odoo/documentation/blob/19.0/content/administration/odoo_sh/getting_started/create.rst) | Hosting y límites |
| [Deployment](https://www.odoo.com/documentation/19.0/administration/on_premise/deploy.html) | Operación self-hosted |
| [Upgrade scripts](https://github.com/odoo/documentation/blob/19.0/content/developer/reference/upgrades/upgrade_scripts.rst) | Migración de módulos |
| [Código Odoo](https://github.com/odoo/odoo) | Contratos de la rama instalada |

Para OCA/terceros inspecciona rama, licencia, mantenimiento, dependencias y documentación
original; no son necesariamente módulos oficiales. Para fiscalidad y proveedores de
pago consulta localización oficial y autoridad/documentación del proveedor vigente.
Un conector MCP debe verificarse por proveedor y herramientas, no por recuerdo.
