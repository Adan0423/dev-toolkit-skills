# Fuentes oficiales

Investigación inicial: 2026-09-30. Revalida capacidades, planes, versión/editor y APIs
antes de aplicar. Información comercial no sustituye schemas/permisos reales del sitio.

| Fuente | Aplicación |
|---|---|
| [Elementor MCP](https://elementor.com/mcp/) | Compatibilidad de layouts, acceso y dependencias |
| [Data Structure](https://developers.elementor.com/docs/data-structure/) | Formato/documentos importables |
| [Site Settings](https://developers.elementor.com/docs/editor/site-settings-panel) | Sistema global |
| [Responsive editing](https://elementor.com/help/responsive-editing/) | Controles del editor actual |
| [Mobile editing](https://elementor.com/help/mobile-editing/) | Ajustes y breakpoints |
| [Herencia responsive](https://elementor.com/help/inherited-responsive-values/) | Cascada de controles |
| [Theme Builder](https://elementor.com/help/the-elementor-theme-builder/) | Plantillas dinámicas/condiciones |
| [Woo REST](https://developer.woocommerce.com/docs/apis/rest-api/) | Administración de catálogo |
| [Woo Store API](https://developer.woocommerce.com/docs/apis/store-api/) | Catálogo/carrito/checkout público |
| [Woo HPOS](https://developer.woocommerce.com/docs/features/orders/high-performance-order-storage/) | Compatibilidad de almacenamiento |
| [WordPress MCP Adapter](https://github.com/WordPress/mcp-adapter) | Abilities/permisos |
| [REST autenticación](https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/) | Acceso de datos WP |
| [Posts](https://developer.wordpress.org/rest-api/reference/posts/) | Editorial |
| [Media](https://developer.wordpress.org/rest-api/reference/media/) | Biblioteca |
| [WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Accesibilidad |

Para plugins específicos, pagos, ACF, traducción, dark mode, formularios, SEO y caché,
consulta documentación oficial y licencia del proveedor elegido. No recomienda marcas
por recuerdo ni instala addons genéricos sin evaluar el sitio.
