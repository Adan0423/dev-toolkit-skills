# Fuentes oficiales y vigencia

Investigación inicial 2026-09-30. Revalida versiones y documentación pertinente antes
de generar código, instalar adaptadores o configurar cuenta. No usar trunk como
garantía de compatibilidad con una instalación estable.

| Fuente | Uso |
|---|---|
| [Theme Handbook](https://developer.wordpress.org/themes/) | Arquitectura y APIs |
| [Estructura](https://developer.wordpress.org/themes/core-concepts/theme-structure/) | Archivos de temas de bloques |
| [theme.json](https://developer.wordpress.org/themes/global-settings-and-styles/introduction-to-theme-json/) | Editor, estilos y configuración |
| [Assets](https://developer.wordpress.org/themes/core-concepts/including-assets/) | Enqueue y dependencias |
| [Template hierarchy](https://developer.wordpress.org/themes/basics/template-hierarchy/) | Elegir templates según consulta |
| [Child themes](https://developer.wordpress.org/themes/advanced-topics/child-themes/) | Extender tema padre |
| [Block accessibility](https://developer.wordpress.org/themes/classic-themes/functionality/block-theme-accessibility/) | Semántica y accesibilidad |
| [Autenticación REST](https://developer.wordpress.org/rest-api/using-the-rest-api/authentication/) | Cookies/nonces y Application Passwords |
| [Posts REST](https://developer.wordpress.org/rest-api/reference/posts/) | Campos y operaciones de artículos |
| [Media REST](https://developer.wordpress.org/rest-api/reference/media/) | Attachments y metadatos |
| [Settings REST](https://developer.wordpress.org/rest-api/reference/settings/) | Ajustes disponibles |
| [WP-CLI](https://developer.wordpress.org/cli/commands/) | Comandos realmente soportados |
| [MCP Adapter oficial](https://github.com/WordPress/mcp-adapter) | Capacidades, compatibilidad y configuración |
| [Introducción oficial MCP](https://developer.wordpress.org/news/2026/02/from-abilities-to-ai-agents-introducing-the-wordpress-mcp-adapter/) | Relación Abilities API/MCP |
| [WCAG 2.2](https://www.w3.org/TR/WCAG22/) | Referencia accesibilidad |

Para WordPress.com, WooCommerce, Gutenberg experimental o plugins concretos, consulta
documentación oficial del proveedor/versiones detectadas; no infieras disponibilidad
de una capacidad por el nombre WordPress. APIs MCP son evolutivas: descubre schemas.
