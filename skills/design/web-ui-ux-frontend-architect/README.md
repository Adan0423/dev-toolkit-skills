# Web UI/UX & Frontend Architect

Skill para diseñar e implementar sitios y sistemas web modernos sin sacrificar arquitectura frontend.

## Capacidades principales

- Analysis First.
- Proyectos existentes y desde cero.
- UI/UX moderno basado en el producto.
- Tailwind CSS o Bootstrap según contexto.
- Iconografía coherente.
- Responsive real y accesibilidad.
- Módulos, componentes, layouts y lógica reutilizable.
- Reorganización automática de frontends desordenados con guardrails.
- Visual/Responsive/Accessibility QA.
- Investigación web adaptativa.

## Validación local

```bash
python scripts/validate_skill.py
python scripts/audit_frontend_structure.py /ruta/al/proyecto
```

El auditor es conservador: reporta señales de deuda estructural; no elimina ni modifica archivos.
