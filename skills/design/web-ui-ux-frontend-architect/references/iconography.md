# Iconografía

Objetivo: lenguaje visual coherente y accesible.

- Elige una familia primaria.
- Normaliza tamaño, stroke y alineación.
- Usa iconos familiares para acciones comunes.
- Añade texto/tooltip/accessible name cuando el significado no sea evidente.
- No uses únicamente color para representar estado.
- No mezcles outline/filled de forma accidental.
- Usa iconos decorativos como `aria-hidden` cuando corresponda.
