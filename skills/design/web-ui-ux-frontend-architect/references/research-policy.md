# Política de investigación

Investiga solo cuando mejore precisión o actualidad.

Orden de fuentes:
1. documentación oficial del framework/plataforma;
2. estándares W3C/WAI y MDN para web platform;
3. documentación oficial de Tailwind/Bootstrap/librería elegida;
4. repositorios oficiales;
5. design systems oficiales;
6. fuentes secundarias para benchmarking/tendencias.

No copies interfaces de terceros. Usa referencias para entender patrones y restricciones.

Cuando una versión actual cambie la API, verifica antes de generar código.
