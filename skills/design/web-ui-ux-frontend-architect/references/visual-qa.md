# Visual QA

## Flujo

`RUN → OBSERVE → RESIZE → INTERACT → INSPECT CONSOLE → FIX → REPEAT`

## Revisar

- alineación y spacing;
- overflow horizontal;
- truncamiento inesperado;
- layout al aumentar texto/zoom;
- sticky/fixed elements;
- modales y dropdowns;
- tablas y formularios;
- estados de carga/error/vacío;
- foco y teclado;
- light/dark;
- responsive de componentes reutilizados en distintos contenedores;
- regresiones en páginas que usan componentes compartidos.
