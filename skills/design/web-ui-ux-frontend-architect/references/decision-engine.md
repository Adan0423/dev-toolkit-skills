# Motor de decisión

## DESIGN_FIRST
Usa si:
- producto nuevo;
- rediseño completo;
- múltiples flujos inseguros;
- navegación/IA debe cambiar;
- el costo de implementar una idea equivocada es alto.

## CODE_FIRST
Usa si:
- cambio localizado;
- patrón existente claro;
- feedback rápido en navegador;
- UI funcional que necesita modernización incremental.

## HYBRID
Usa si:
- necesitas definir primero arquitectura/design system;
- algunas pantallas requieren exploración y otras pueden implementarse directamente;
- una migración incremental se beneficia de prototipar componentes base.
