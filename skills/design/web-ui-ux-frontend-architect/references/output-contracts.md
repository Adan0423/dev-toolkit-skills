# Contratos de salida

## Auditoría

Entrega:
- hallazgos priorizados;
- impacto UX/técnico;
- arquitectura actual resumida;
- propuesta de reorganización;
- acciones ejecutadas o recomendadas;
- riesgos.

## Implementación

Entrega:
- archivos/áreas modificadas;
- módulos/componentes creados;
- design system/tokens relevantes;
- responsive/accessibility implementados;
- comandos de validación ejecutados y resultado;
- pendientes genuinos.

## Proyecto nuevo

Entrega:
- brief interpretado;
- arquitectura IA/frontend;
- módulos;
- design system;
- pantallas/flujos;
- implementación inicial;
- validación.
