# Research Policy

## Search only when it changes the decision
Research is mandatory when the recommendation depends on current:
- major versions
- framework support
- RSC/SSR behavior
- package names/install commands
- browser support
- deprecations
- maintenance status
- licensing / commercial tiers
- migration paths

## Source priority
1. Official documentation
2. Official changelog/releases/repository
3. Standards bodies (W3C/WAI)
4. Framework documentation for integration constraints

Avoid using blog listicles as the basis for compatibility claims.

## Research output
Record only decision-relevant facts. Do not paste documentation dumps.
