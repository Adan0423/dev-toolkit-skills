# Source Baseline

Baseline checked 2026-08-13. Always re-check official docs when current behavior matters.

Key verified principles:
- Tailwind provides mobile-first responsive variants and container queries.
- Panda CSS generates atomic CSS at build time with type-safe styling primitives and tokens.
- Radix Primitives are low-level unstyled React primitives with WAI-ARIA-oriented accessibility behavior.
- Ark UI is headless and supports React, Solid, Vue, and Svelte.
- Bits UI provides headless primitives for Svelte 5.
- Material UI is a styled React component library and current docs should be checked for the active stable major.
- Ant Design explicitly targets enterprise-class React web applications.
- shadcn/ui changed new-project defaults in 2026: Base UI is the default primitive option while Radix remains supported.
- Bootstrap 5.3 remains mobile-first and exposes a Sass-based Utility API.
- Motion is the current package/name for the animation library formerly commonly referenced as Framer Motion; current install/API should be checked before coding.
- Lucide exposes tree-shakeable SVG icon packages.
