# Adaptive research policy

Research is optional and evidence-driven.

## Research is warranted when

- a dependency/framework name is unfamiliar
- a version-specific installation command is needed
- a badge URL/schema must be constructed
- Mermaid syntax/features may have changed
- an external image/logo/license is being considered
- repository hosting rules affect file discovery/rendering
- a tool's current support/deprecation state matters

## Source priority

1. official documentation
2. standards/specifications
3. canonical project repository
4. official release notes/changelogs
5. reputable secondary technical sources only when necessary

## Citation/source notes

Documentation generated inside a repository normally should not be cluttered with external citations unless the document's purpose requires them. Instead:
- link official technology docs in a Resources/References section when useful
- preserve license/attribution requirements for third-party assets
- do not cite random blog posts as authority for the project's own architecture
