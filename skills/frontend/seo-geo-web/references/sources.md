# Fuentes primarias

Investigación inicial: 2026-09-30. Revalida la fuente relevante al ejecutar y registra
fecha, URL y regla aplicada. En caso de bloqueo busca versión oficial actual; no uses
un resumen de búsqueda como evidencia suficiente para una API. No son garantías de ranking.
