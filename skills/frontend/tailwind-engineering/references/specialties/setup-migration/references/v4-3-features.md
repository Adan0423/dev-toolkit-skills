# Tailwind CSS v4.3 feature map

Tailwind CSS v4.3 was announced on 2026-05-08.

## v4.3 additions

- First-party scrollbar styling utilities.
- `@container-size` for size containers, including named size containers.
- `zoom-*` utilities.
- `tab-*` utilities for `tab-size`.
- Stacked `@variant` support in CSS.
- Compound `@variant` support in CSS.
- `--default(...)` fallback values for functional utilities.

## v4.2 capabilities included in the v4.3 generation

- `mauve`, `olive`, `mist`, and `taupe` palettes.
- First-party webpack plugin.
- Additional logical-property utilities.
- `font-features-*` utilities.

## Usage principle

Prefer features because they reduce complexity or improve semantics, not because they are new.
