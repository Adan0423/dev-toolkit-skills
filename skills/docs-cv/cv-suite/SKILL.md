# CV Suite

Identifica CV/fuentes del usuario, objetivo, idioma y vacante si existe. No presupone
un puesto técnico ni obliga a una página para todas las trayectorias. No inventa
experiencia, títulos, fechas, métricas, habilidades o identidad para llenar vacíos.

| Necesidad | Guía |
|---|---|
| Estructurar/maquetar CV Harvard legible | [format](references/specialties/format/guide.md) |
| Adaptar a vacante, revisar ATS o redactar logros con datos reales | [ats](references/specialties/ats/guide.md) |

Lee una guía inicial. Si piden formato, no necesita una vacante. Si piden adaptación,
usa descripción real y hechos verificables; si falta, adapta al objetivo declarado y
señala lo pendiente. Auditoría/revisión no autoriza enviar solicitudes ni contactar
reclutadores. No lee ambas especialidades por rutina ni promete "ATS perfecto".
Las guías son procedimientos internos con recursos relativos a su carpeta.

Evalúa orden, legibilidad, selección de experiencia y extracción de texto cuando se
genere archivo. Normas de longitud dependen de propósito y trayectoria; explica una
elección que afecte información. Corrección gramatical no transforma hechos.
Para PDF/DOCX usa herramientas/skills disponibles apropiadas, sin asumir instalación;
si no puedes generar archivo, entrega contenido listo y limitación concreta.
Entrega artefacto, cambios y datos pendientes, sin publicar información personal.
